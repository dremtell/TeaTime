Приложение - таймер для удобного проведения чайной церемонии. Выставляешь время первого пролива и шаг прибавления для последующих проливов (автоматически при заходе в приложение стоит 20 сек и 20 сек, но только потому что мне так удобно, эти значения можно спокойно менять), теперь когда будешь готов нажимай СТАРТ и начнётся первый отсчёт времени, по его окончанию можно услышать звуковое уведомление, а так же заметить что изменилась центральная картинка и цвет заднего фона.

Приложение создавал для себя, но посчитал нужным чтобы оно было в общем пользовании. Скорее всего буду что-нибудь дорабатывать, идеи есть, нужно время для их реализации.

Наилучших всем чайных церемоний.
